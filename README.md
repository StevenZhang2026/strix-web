# Strix Web 控制台

给 [Strix](https://github.com/usestrix/strix) 加一层本地 Web 控制台：向导式发起渗透测试、
实时进度可视化、中文报告、授权护栏。

核心设计约束是三条：**LLM 可切换**、**谁用谁的 Key**、**Key 绝不落盘**。

## 安全姿态（现在就该知道的）

这个工具**只为本机使用设计**，没有做多用户、没有做数据隔离：

- 对外只经 `nginx` 终止 TLS，**绑 `127.0.0.1:443`**，不监听 80；`api` / `web` 不发布端口。
- 证书 SAN 只含 `localhost` / `127.0.0.1` / `::1`。这不只是浏览器兼容性，
  它挡住 DNS rebinding。
- 有一个单账号登录，但**它挡的是「同机另一个账号顺手打开浏览器」和「浏览器里的
  其它标签页」**。它对本机管理员不构成边界。
- **Strix 需要 docker.sock 来创建沙箱容器，而挂 docker.sock ≈ 宿主 root。**
  这一条无法在使用 Strix 的前提下消除。

LLM API Key 只存在于 `api` 进程内存与扫描子进程的环境变量里 —— 不进数据库、
不进日志、不进命令行参数、不进 `.env`、不进镜像。代价是 `api` 重启即需重新输入。

完整的风险清单（包括已知且接受的残余风险）将来在 `docs/SECURITY-zh.md`，尚未写。

## 与 Strix 的关系

本项目**依赖** `strix-agent`（Apache-2.0），精确 pin 在 `1.5.3`，不修改也不分发它的代码。

本项目**不代理** Strix 自带的 SPA，也**不包含**任何向第三方外发数据的代码路径 ——
`STRIX_TELEMETRY=false` 是强制的。这是本项目存在的理由之一。

本仓库自己的代码是 MIT（见 [`LICENSE`](LICENSE)）。

## 环境要求

macOS 或 Linux，且都要求 Docker Desktop。**原生 Windows 不支持**（路径含冒号，
同路径挂载不成立 —— 请在 WSL2 内运行）。

Docker VM 内存 ≥ 4 GB、CPU ≥ 2 核、数据目录可用 ≥ 10 GB。
这些由 `./setup.sh` 强制校验，低于阻断线会直接退出。
